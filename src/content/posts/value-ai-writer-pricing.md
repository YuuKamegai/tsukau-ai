GMOデジロックが提供するSEO記事生成ツール **Value AI Writer byGMO** の料金は、
「月に何記事作れるか」でプランが分かれています。
料金表としては分かりやすい部類です。

ただ、公式マニュアルまで読むと、この「◯記事」という数字は
**多くの人が想像するものとは別のものを数えています。**

先に結論を書きます。

- カウントが減るのは記事が完成したときではなく、
  **タイトル候補を作成した時点**です。
- 途中でやめてブラウザを閉じても、**その1は戻りません。**
- 料金表で大きく見える「6記事」「20記事」「100記事」といった数字は
  **初月だけの増量分**です。2か月目からは半分になります。
- 定価では、下位3プランの1記事あたり単価は**いずれも280円**で横並びです。
  プランを上げても、上位に行くまでは単価が下がりません。

以下はすべて、**2026年8月30日に[サービスページ](https://one.value-domain.com/value-aiwriter)・
[バリュードメインの製品ページ](https://www.value-domain.com/value-aiwriter/)・
公式ユーザーガイド・利用規約で確認した内容**です。
第三者サイトの数字は使っていません。
**筆者はこのツールを契約しておらず、未実機です。**仕様の読み取りだけを書いています。

料金表には
「**税込・2026年7月9日時点の掲載料金。最新の料金・プラン内容はお申込み画面でご確認ください。**」

断ってある**ことです。筆者が読んだのは2026年8月30日なので、
公式ページ自身の基準日から2か月近く経っています。
契約する前に申込画面で確認してください、というのは公式の指示です。

## 「1記事」は、タイトル候補を出した時点で消える

ここがこのツールの料金を読むうえで一番効く仕様です。
記事作成の公式マニュアルに、そのまま書かれています。

> タイトル候補を作成したタイミングで記事構成数が1消費します

さらに、途中でやめた場合についても明記があります。

> 記事が作成されず構成数のみ消費されます

つまり、**タイトル候補を出させて、気に入らなかったのでやめる。
これで1記事分が減ります。**完成した記事は0本です。

料金表の側は「記事作成数」、マニュアルの側は「記事構成数」と、
呼び方も揃っていません。数えているのは後者です。

「月10記事のプランなら10本書ける」と読むと、実際には
**10回タイトル候補を作れる**という意味に近くなります。
狙ったキーワードで構成を出し直しながら詰めていく使い方をすると、
公開できた記事の数は表の数字より確実に少なくなります。

なお、**再生成が追加で消費するのかどうかは、
公式マニュアルからは読み取れませんでした。**
消費されるのが「タイトル候補の作成時」だという記述だけで、
その後の見出しや本文の作り直しについての説明が見当たりません。

## 「初回増量」は初月だけ

料金表で目に入るのは増量後の数字のほうですが、これには注記があります。

> 初回増量は初月の増量特典です

2か月目からは増量前の数字に戻ります。
**月額はそのままで、作れる数が半分になる**ということです。

公式の数字（月額 ÷ 記事作成数）を単純に割った、1記事あたりの単価を出します。
以下は**公式の料金と記事数からの単純計算**で、公式が掲げている数字ではありません。

| プラン | 初月（増量あり） | 2か月目以降 |
| --- | --- | --- |
| エントリー | 140円 | **280円** |
| エントリープラス | 140円 | **280円** |
| ベーシック | 140円 | **280円** |
| ベーシックプラス | 137円 | 274円 |
| プロ | 107.8円 | 215.6円 |
| エキスパート | 54.7円 | 109.45円 |

**下位3プランは1記事あたり280円で完全に横並びです。**
エントリーからベーシックへ上げても、単価は1円も下がりません。
このツールで「上げると得になる」のはベーシックプラス以降で、
はっきり下がるのはプロ（215.6円）とエキスパート（109.45円）です。

裏を返すと、**月10記事までのレンジではプラン選びに価格上の正解がありません。**
必要な本数のところを取ればよく、それ以上でも以下でもない、という料金設計です。

## コアサーバーV2とのセット割は、単価を揃えにいっている

セット割の価格も同じ単価で割ってみると、構造がはっきりします。

| プラン | セット割の月額 | 1記事あたり |
| --- | --- | --- |
| エントリー | 480円 | 160円 |
| エントリープラス | 800円 | 160円 |
| ベーシック | 1,600円 | 160円 |
| ベーシックプラス | 3,200円 | 160円 |
| プロ | 8,000円 | 160円 |
| エキスパート | 35,000円 | 87.5円 |

**エントリーからプロまで、1記事あたりがぴたりと160円で揃います。**
公式が「最大約43%割引」と書きながらプロは約26%、エキスパートは約20%に
とどまるのは、割引率をプランごとに変えているというより、
**単価を一律に置き直した結果**と読むのが素直です。

ただし、**この比較にはコアサーバーV2の料金が入っていません。**
セット割はサーバー契約が前提なので、実際の支出はここにサーバー代が乗ります。
**コアサーバーV2側の料金は今回確認していません。**
サーバーをもともと契約する予定がないなら、この列は自分の価格表ではありません。

## 契約と解約の条件

利用規約とユーザーガイドから、料金以外で効く条件を拾います。

- **1か月単位のサブスクリプション契約**。
  「**契約の更新は有効期限の5日前から毎日0時に自動更新が行われます**」。
- 解約は「いつでも」できますが、
  **日割りも返金もありません**。規約第7条2項に
  「**有効期限途中での解約があった場合でも、日割・返金はしないものとします**」、
  第5条2項に「**当社は、すでに受領した利用料金等を一切精算、返金しないものとします**」
  とあります。解約予約は**自動更新（有効期限日の5日前）までに**行う必要があります。
- **プランアップは1か月分の差額が即請求され、日割り計算はされません。**
  「**プランのアップグレードは１ヶ月間の差額が請求されます。日割り計算は行いません。**」
- **プランダウンでの返金はありません。**
- プランアップで枠を増やしても、
  「**その期限までに増えた制限数を使い切らなければ「作成制限リセット日」で上限が
  リセットされてしまいます**」。月末近くに上げると、増えた分を使い切れません。
- 自動更新の失敗や解約予約で期限切れになった契約は、
  **期限切れ後最大30日間は復旧できます**。

「足りなくなったら上げる」をやると、**日割りなしの差額を払ったうえに、
増えた枠がリセット日で消える**という並びになります。
上げるなら月の初めのほうが有利、という構造です。

## 無料で使える範囲

- **フリープラン**があります。「月間 1記事（毎月無料）」で、初回増量で3記事。
  期間限定のトライアルではなく、毎月1記事の枠が続く書き方です。
- 別に「**お試し5日間無料**」の導線があります。ただし
  「**お試し契約を同時にお申込みいただけるのは1件までです**」という制限付きです。

**このお試しについて、カードの登録が必要か、5日を過ぎたときに自動で
課金が始まるのかは、公式ページからは確認できませんでした。**
申込手順の説明には支払い方法を選ぶステップがありますが、
お試し契約でそれが必須なのかは書かれていません。
[Rimo Voiceの「まずは無料ではじめる」が実は1週間トライアルだった件](/posts/rimo-voice-pricing)と
同じで、無料の入口は**期間と、期間が終わった後の挙動**をセットで確認しないと読めません。

## プランで変わる機能

料金の差は記事数だけではありません。公式ページに書かれている範囲では、

- **サジェストキーワード調査 → プロ・エキスパート限定**
- **競合サイト獲得キーワード調査 → エキスパート限定**
- 検索結果から選択してAIで見出し構成を作る機能 → **プロプラン以上**
- 本文生成AIの選択（GPT-4o,4.1 / Claude4.0 / Gemini2.5-Pro）は**全プラン**

キーワード調査まで含めて使うつもりなら、記事数ではなく機能でプランが決まります。
月5記事しか書かなくてもサジェスト調査が要るならプロ（10,780円）です。

生成される記事の分量については、公式に
「**1記事あたりの目安で15,000文字～20,000文字になる傾向が多いです**」とあります。

画像生成もありますが、**「画像作成に関しても作成可能数はプランによって異なります」
と書かれているだけで、プランごとの枚数は公式に見つけられませんでした。**
生成した画像は1か月で削除される旨の記載があります。

## この記事で確認できなかったこと

正直に書きます。

- **未実機です。**契約していないので、1記事の生成にかかる実時間、
  出力の質、カウントが実際にどの操作で減るかは確認していません。
  上に書いたのはすべて公式の記述の読み取りです。
- **再生成でカウントが追加消費されるかは不明です。**
  マニュアルはタイトル候補作成時の消費しか書いていません。
- **AIモデルの記述が公式内で食い違っています。**
  製品ページは「GPT-4o,4.1 / Claude4.0 / Gemini2.5-Pro を全プランで選択できます」ですが、
  記事作成のユーザーガイドには「GPT4は※エントリープランでは使用できません」と、
  GPT-3.5 / GPT-4 世代の記述が残っています。
  マニュアルが更新されていないだけに見えますが、**どちらが現行かは断定できません。**
- **お試し5日間の条件**（カード要否・終了後の自動課金）は確認できませんでした。
- **画像生成のプラン別の上限枚数**は公式に見当たりませんでした。
- **コアサーバーV2の料金は確認していません。**セット割の実質負担は出せていません。
- 公式の掲載料金の基準日は**2026年7月9日**です。筆者が読んだ8月30日時点で
  変わっていないという保証は、公式自身がしていません。

## まとめ

Value AI Writerの料金表を読むときに揃えるべき単位は、月額ではなく
**「1回のタイトル候補生成」**です。そこが料金の最小単位で、
記事が完成したかどうかとは関係なく減ります。

そのうえで見ると、

- 月10記事までは**どのプランでも1記事280円**。価格で選ぶ意味がない
- 表の大きい数字は**初月だけ**
- 上げるなら**月の初め**（差額は日割りなし、増えた枠はリセット日で消える）

料金表に出ている単位が、自分が数えたい単位と一致しているか。
[ConoHa AI Canvasが「枚数ではなく起動時間」で課金していた件](/posts/conoha-ai-canvas-pricing)や、
[文字起こしツールの料金を税込・年払いで揃え直した比較](/posts/ai-transcription-price-comparison)と、
確認する順番は同じです。単位を確かめてから、金額を比べる。
